#### Definition

**Methods**
Functions inside a class that define what an object can do.

___
#### Syntax

**Syntax 1**
```c#
accessModifier returnType
MethodName()
{
  // Code
}

objectName.MethodName();
```

___
#### Examples

**Example 1**
```c#
public void Drive()
{
  Console.WriteLine("Driving");
}

myCar.Drive();
```
