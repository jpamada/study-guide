**Instantiate**

**FOUR PILLARS**
**Inheritance**
- children class inherits attributes and methods from the parent class

**Abstraction**
- hides complex logic
- similar to inheritance but can use policy if `abstract class` is used 

**Encapsulation**
- hides data (private attributes)
- control access through methods
- add validation
- getters and setters

**Polymorphism**
- objects can be treated a group based on their parent class
- happens when objects are accessed via inheritance or interfaces.

**ADVANCE**
**`this`**
- It refers to the object that is currently using the function

**Constructor**
- method used to initialize attributes when object is created

**Dependency Injection**
- a class uses another class (dependency)
- the dependency is provided through a constructor
- the dependency is created outside and passed into the object

**Interface
- acts like inheritance and abstraction
- can implement multiple interface in a single class
- set of rules that a class must follow
