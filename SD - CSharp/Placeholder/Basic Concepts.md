#### Examples

**[[Class]]**
Blueprint/template for creating objects.

**[[Object]]**
An entity or real instance of a class.

**[[Properties]]**
Variables inside a class that store data.

**[[Methods]]**
Functions inside a class that define what an object can do.

**[[Instantiation]]**
The process of creating an object from a class.

**[[Constructor]]**
Special method used to initialize an object when it is created.

**[[Instance]]**
An object created from a class.

**[[this]]**
Refers to the current instance (object) of the class.
