#### Examples

**[[Animated.timing()]]**
Animates a value over time using an easing curve.

**[[Animated.spring()]]**
Animates a value using a spring physics model.

**[[Animated.decay()]]**
Animates a value from an initial velocity and gradually slows it to a stop based on a decay coefficient.
