#### Definition

**Component Packages**
These are the components outside the in-built React Native components that are also useful.

___
#### Examples

**[[Picker]]**
A component package that allows the user to select one option from a list of choices.

**[[KeyboardAwareScrollView]]**
A scrollable view designed to work with the keyboard so content can remain accessible when the keyboard appears.

**[[KeyboardStickyView]]**
A keyboard-aware view designed to keep content positioned relative to the keyboard.

**[[04.01 Animated]]**
React Native's built-in animation API for creating fluid animations.

**[[Controller]]**
A React Hook Form component that acts as an adapter between React Hook Form and controlled/custom input components.

**[[Svg]]**
The root/container for an SVG drawing.

**[[Rect]]**
An SVG component representing a rectangle.

**[[Text]]**
places text inside an SVG drawing. Can be renamed as `SvgText` to avoid confusion.
