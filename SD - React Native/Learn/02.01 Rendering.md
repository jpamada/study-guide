#### Definition

**Rendering**
Determines what the UI should look like based on the current state, props, and component logic. There are three ways that causes rendering.

___
#### Examples

**[[Initial Render]]**
The first time the component appears. Uses the default state and props.

**[[State Update]]**
Updating state causes the screen render again. It doesn't need to throw away the entire screen.

**[[Parent Render]]**
A parent components rendering can cause its child components to render.
