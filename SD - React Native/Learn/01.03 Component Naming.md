#### Definition

**Component Naming**
Instead of naming components randomly, follow the intended naming.

___
#### Examples

**...Screen**
For components that handle multiple components.

**...Layout**
For components that handle multiple screen.

**...Header**
For header components.

**...Footer**
For footer components.

**...List**
For list components.

**...Item**
For item components.

**...Card**
For card components.

**...Modal**
For modal components. Avoid using the built-in Modal component.

**...Button**
For button components. Make sure to describe the function of the button first.

**...Input**
For input components.

**Descriptive Names**
For specific use components like `ErrorScreen`.

**Generic Names**
If the component has a generic usage.
