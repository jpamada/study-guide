#### Definition

**Components**
Used to display user interface and can interact with the user.

___
#### Examples

**[[Stack]]**
Creates a stack navigator, where screens are placed on top of one another as you navigate.

**[[Tabs]]**
Creates a tab-based navigation layout, allowing users to switch between different sections of an app.

**[[View]]**
For building and arranging UI.

**[[ScrollView]]**
Provides a scrollable container for multiple components and views.

**[[Fragment]]**
Groups multiple elements without adding a wrapper element.

**[[Text]]**
Display text.

**[[TextInput]]**
Enters text into the app using the keyboard.

**[[Animated]]**
React Native's built-in animation API for creating fluid animations.

**[[Picker]]**
A package that allows the user to select one option from a list of choices.

**[[Pressable]]**
Can detect different stages of press interactions on its children.

**[[Modal]]**
Used to present content above the enclosing view.

**[[FlatList]]**
Allows to render items efficiently.

**[[Image]]**
Display image.

**[[ActivityIndicator]]**
Display loading indicator.

**[[Suspense]]**
Allows React to display a fallback UI while its children are not yet ready to render.

**[[KeyboardAwareScrollView]]**
A scrollable view designed to work with the keyboard so content can remain accessible when the keyboard appears.

**[[KeyboardStickyView]]**
A keyboard-aware view designed to keep content positioned relative to the keyboard.

**[[Controller]]**
A React Hook Form component that acts as an adapter between React Hook Form and controlled/custom input components.

**[[Svg]]**
The root/container for an SVG drawing.

**[[Rect]]**
An SVG component representing a rectangle.

**[[Text]]**
places text inside an SVG drawing. Can be renamed as `SvgText` to avoid confusion.
