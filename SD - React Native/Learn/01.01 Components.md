#### Definition

**Components**
Used to display user interface and can interact with the user.

___
#### Examples

**[[Stack]]**
Creates a stack navigator, where screens are placed on top of one another as you navigate.

**[[Tabs]]**
Creates a tab-based navigation layout, allowing users to switch between different sections of an app.

**[[View]]**
For building and arranging UI.

**[[ScrollView]]**
Provides a scrollable container for multiple components and views.

**[[Fragment]]**
Groups multiple elements without adding a wrapper element.

**[[Text]]**
Display text.

**[[TextInput]]**
Enters text into the app using the keyboard.

**[[Pressable]]**
Can detect different stages of press interactions on its children.

**[[Modal]]**
Used to present content above the enclosing view.

**[[FlatList]]**
Allows to render items efficiently.

**[[Image]]**
Display image.

**[[ActivityIndicator]]**
Display loading indicator.

**[[Suspense]]**
Allows React to display a fallback UI while its children are not yet ready to render.
