#### Examples

**[[Animated.View]]**
Can handle the animated value and style the component.

**[[Animated.Text]]**
An animated version of React Native's Text component.

**[[Animated.Image]]**
An animated version of React Native's Image component.

**[[Animated.ScrollView]]**
A ScrollView that can be controlled or animated using Animated values/events.

**[[Animated.FlatList]]**
An animated version of FlatList, useful for animating list items or scroll position.

**[[Animated.SectionList]]**
An animated version of SectionList, useful for animating sectioned lists and their scrolling.
