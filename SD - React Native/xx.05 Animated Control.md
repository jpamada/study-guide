#### Examples

**[[start()]]**
Starts the animation and accepts an optional callback fired when the animation ends.

**[[stop()]]**
Halts whatever animation is currently running on that value, wherever it currently is.

**[[reset()]]**
Stops the animation and resets the value back to its original starting point.
