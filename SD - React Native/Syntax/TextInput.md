**TextInput**

#### Props

**multiline**
Allow multiple line similar to text box.

**value**
The current value of the text input.

**onChangeText**
Get/update the current text.

**[[onFocus]]**
React to the user entering the input

**onBlur**
Validate/cleanup when leaving the input.

**onSubmitEditing**
Handle Enter/Done/Next.
