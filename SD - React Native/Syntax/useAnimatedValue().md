#### Definition

**useAnimatedValue()**
The newer version and the wrapper of `Animated.Value.` already contains `useRef.`

___
#### Syntax

**Basic Syntax**
This is the less boilterplate code of using value because it already have `useRef.`
```ts
const value = useAnimatedValue(0);
```

___
#### Example

**Basic Example**
```ts
const opacity = useAnimatedValue(0);
```
