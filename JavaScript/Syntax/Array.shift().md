#### Definition

**Array.shift()**
Removes and returns the first element of an array.

___
#### Syntax

**Syntax 1**
```js
array.shift()
```

___
#### Examples

**Example 1**
```js
const arr = ["1", "2", "3"];
const first = myArray.shift();

// arr = ["2", "3"] 
// first = "1"
```
