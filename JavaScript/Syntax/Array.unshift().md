#### Definition

**Aray.unshift()**
Adds one or more elements to the beginning of an array.

___
#### Syntax

**Syntax 1**
```js
array.unshift(
	element1, element2, ...
);
```

___
#### Examples

**Example 1**
```js
const arr = ["1", "2", "3"];
arr.unshift("4", "5");

// arr = ["4", "5", "1", "2", "3"]
```
