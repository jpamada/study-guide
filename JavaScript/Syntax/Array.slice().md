#### Definition

**Array.Slice()**
Returns a portion of an array without modifying the original array.

___
#### Syntax

**Syntax 1**
```js
array.slice(start, end)
```

___
#### Examples

**Example 1**
```js
let arr = [
	"a", "b", "c", "d", "e"
];

arr = arr.slice(1, 4); 

// arr = ["b", "c", "d"]
```
