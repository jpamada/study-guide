#### Definition

**Map.forEach()**
Runs a callback for every key-value pair.

___
#### Syntax

**Syntax 1**
```js
map.forEach((value, key) => {
  // code
});
```

___
#### Examples

**Example 1**
```js
user.forEach((value, key) => {
  console.log(`${key}: ${value}`);
});
```
