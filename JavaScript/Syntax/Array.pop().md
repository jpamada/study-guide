#### Definition

**Array.pop()**
Removes and returns the last element of an array.

___
#### Syntax

**Syntax 1**
```js
array.pop()
```

___
#### Examples

**Example 1**
```js
const arr = ["1", "2", "3"];
const last = myArray.pop();

// arr = ["1", "2"];
// last = "3"
```
