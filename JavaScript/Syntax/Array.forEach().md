#### Definition

**Array.forEach**
Runs a function for every array element.

___
#### Syntax

**Syntax 1**
```js
array.forEach(
	(element, index, array) => {
	  // Code
	}
)
```

___
#### Examples

**Example 1**
```js
const arr = ["a", "b", "c"];

arr.forEach((element) => {
	console.log(element); 
});
```
