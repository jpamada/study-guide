#### Definition

**Promise Composition**
Promise composition combines multiple asynchronous operations.

___
#### Examples

**[[Promise.all()]]**
Waits for all Promises to succeed.

**[[Promise.allSettled()]]**
Waits until all Promises finish, whether they succeed or fail.

**[[Promise.any()]]**
Returns the first successfully fulfilled Promise.

___
##### Related Topic

**Concurrent**
Start independent operations together.

**Sequential**
Use sequential execution when the next operation needs the previous result.
