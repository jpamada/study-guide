#### Definition

**What is a Literal**
Literally adds the value instead of calling a  constructor.

___
#### Examples

**Array Literals**
Uses `[]` instead of `new Array().`

**Boolean Literals**
Uses `true` and `false` instead of `new Boolean().`

**Numeric Literals**
Uses numbers instead of `new Number().`

**Object Literals**
Uses `{}` instead of `new Object.`

**RegExp Literals**
Uses `/ /` directly instead of `new RegExp().`

**String Literals**
Uses single or double quotations instead of `new String().`

**Template Literals**
Used backticks instead of manually using string concatenations or `${}.`
