#### Examples

**[[length]]**
Returns the number of characters in a string or items in an array.

**[[toLowerCase()]]**
Converts a string to lowercase.

**[[toUpperCase()]]**
Converts a string to uppercase.

**[[includes()]]**
Checks whether a string or array contains a specified value.

**[[trim()]]**
Removes whitespace from the beginning and end of a string.

**[[replace()]]**
Replaces a matching value with another value.

**[[replaceAll()]]**
Replaces all matching values.

**[[split()]]**
Splits a string into an array.

**[[join()]]**
Joins array elements into a single string.

**[[slice()]]**
Extracts a portion of a string or array and returns it as a new value.
