#### Examples

**[[String.parseInt()]]**
Only returns whole numbers. Best practice to use with radix parameter.

**[[String.parseFloat()]]**  
Returns a decimal number even when there is a non-numeric string at the end.

**[[Number()]]**  
Converts a string or other value to the Number type.

**Number With Binary Operator**  
Concatenates numeric values to strings when partnered with `+` and string

**Number With Unary Operator**  
Unary plus operator is specifically a numeric conversion operator.
