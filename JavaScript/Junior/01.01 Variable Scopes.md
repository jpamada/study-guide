#### Definition

**What is a Scope**
Determines where a variable is available in your code.

___
#### Examples

**Global Scope** 
The default scope for all code running in script mode.

**Module Scope**
The scope for code running in module mode.

**Function Scope**
The scope created with a function.

**Block Scope**
Specifically for `let` and `const` variables.
