#### Definition

**[[Map()]]**
 A key/value map that can iterate its elements in insertion order.
 
___
#### Examples

**[[Map.set()]]**
Adds or updates a key-value pair.

**[[Map.get()]]**
Returns the value associated with a key.

**[[Map.has()]]**
Checks whether a key exists.

**[[Map.delete()]]**
Removes a key-value pair.

**[[Map.clear()]]**
Removes all key-value pairs.

**[[Map.size()]]**
Returns the number of key-value pairs.

**[[Map.keys()]]**
Returns an iterator containing all keys.

**[[Map.values()]]**
Returns an iterator containing all values.

**[[Map.entries()]]**
Returns an iterator containing key-value pairs.

**[[Map.forEach()]]**
Runs a callback for every key-value pair.

___
