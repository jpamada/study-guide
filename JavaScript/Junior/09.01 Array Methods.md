#### Examples

**[[Array.concat()]]**
 Joins two or more arrays and returns a new array.

**[[Array.join()]]**
 joins all elements of an array into a string.

**[[Array.push()]]**
Adds one or more elements to the end of an array.

**[[Array.pop()]]**
Removes and returns the last element of an array.

**[[Array.shift()]]**
Removes and returns the first element of an array.

**[[Array.unshift()]]**
Adds one or more elements to the beginning of an array.

**[[Array.slice()]]**
Returns a portion of an array without modifying the original array.

**[[Array.splice()]]**
Adds, removes, or replaces elements in an array.

**[[Array.flat()]]**
Flattens nested arrays into a single array.

**[[Array.flatMap()]]**
Maps each element and then flattens the result by one level.

**[[Array.sort()]]**
Sorts the elements of an array.

**[[Array.forEach()]]**
Runs a function for every array element.

**[[Array.map()]]**
Creates a new array by transforming every element.

**[[Array.filter()]]**
Creates a new array containing only elements that pass a condition.

**[[Array.find()]]**
Returns the first element that matches a condition.

**[[Array.every()]]**
 Returns true if callback returns true for every item in the array.

**[[Array.some()]]**
Checks if at least one element passes a condition.

**[[Array.reduce()]]**
Combines all array elements into a single value.
