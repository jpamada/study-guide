#### Definition

**[[Set()]]**
A collection that stores unique values. Unlike an array it prevents duplicates.

___
#### Examples

**[[Set.add()]]**
Adds a value.

**[[Set.has()]]**
Checks whether a value exists.

**[[Set.delete()]]**
Removes a value.

**[[Set.clear()]]**
Removes a value.

**[[Set.size()]]**
Returns the number of values.
