#### Definition

**What is a Date Object**
Has a large number of methods for setting, getting, and manipulating dates.

___
#### Examples

**[[new Date()]]**
Creates a Date object.

**[[Date.now()]]**
Returns the current timestamp in milliseconds.

**[[getFullYear()]]**
Returns the year.

**[[getMonth()]]**
Returns the month from 0–11 January to Februar.

**[[getDate()]]**
Returns the day of the month 1–31.

**[[getDay()]]**
Returns the day of the week 0–6 Sunday to Saturday.

**[[getHours()]]**
Returns the hour.

**[[getMinutes()]]**
Returns the minutes.

**[[getSeconds()]]**
Returns the seconds.

**[[toISOString()]]**
Returns the date in ISO 8601 format using UTC.

**[[toLocaleDateString()]]**
Formats the date according to the user's locale.

**[[toLocaleString()]]**
Formats both the date and time.
