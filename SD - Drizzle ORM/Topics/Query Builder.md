#### Examples

**[[Selection Queries]]**
Retrieve data from the database.

**[[Insert Queries]]**
Add new records to the database.

**[[Update Queries]]**
Modify existing records in the database.

**[[Delete Queries]]**
Remove records from the database.

**[[Logical Queries]]**
Combine or negate conditions using logical operators.

**[[Comparison Queries]]**
Compare column values against specific values or conditions.

**[[Join Queries]]**
Combine related data from multiple tables.

**[[Aggregation Queries]]**
Calculate summary values such as count, sum, average, minimum, or maximum.

**[[Grouping Queries]]**
Group rows together based on one or more columns.

**[[Sorting Queries]]**
Arrange query results in ascending or descending order.

**[[Distinct Query]]**
Return only unique results and remove duplicate rows.

**[[Pagination Queries]]**
Retrieve a specific portion of results using limits and offsets.

**[[Returning Query]]**
Return affected rows after an insert, update, or delete operation.

**[[SQL Query]]**
Write raw or custom SQL expressions when Drizzle's standard query methods are not sufficient.
