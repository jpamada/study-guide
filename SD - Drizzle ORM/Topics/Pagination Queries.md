#### Examples

**`limit()`**  
Restricts the maximum number of rows returned.
```ts
.limit(10)
```

**`limit(1)`**  
A special use of `limit()` that restricts the result to at most one row.
```ts
.limit(1)
```

**`offset()`**  
Skips a specified number of rows before returning results.
```ts
.offset(20)
```
