#### Definition

**schema**
Specifies the type of database you're working with.

___
#### Syntax

**Basic Syntax**
```tsx
schema: "./path/to/schema.ts"
```

**Multiple Paths**
```ts
schema: [
	"./path/to/schema.ts",
	"./path/to/schema.ts"
]
```

___
#### Example

**Basic Example**
```tsx
schema: "./src/db/schema.ts"
```
