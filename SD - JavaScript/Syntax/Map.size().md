#### Definition

**Map.size()**
Returns the number of key-value pairs. Size is a property, not a method.

___
#### Syntax

**Syntax 1**
```js
map.size;
```

___
#### Examples

**Example 1**
```js
const user = new Map([
  ["name", "John"],
  ["age", 25],
]);

// user.size = 2
```
