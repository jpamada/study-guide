#### Definition

**Array.push()**
Adds one or more elements to the end of an array.

___
#### Syntax

**Syntax 1**
```js
array.push(element1, element2, ...)
```

___
#### Examples

**Example 1**
```js
const myArray = ["1", "2"];
myArray.push("3"); 
// ["1", "2", "3"]
```
