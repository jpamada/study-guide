#### Definition

**ScrollView**
Allow scrolling for the screen.

___
#### Props

**[[ScrollView.StickyHeaderComponent]]**
Render sticky headers, should be used together with `stickyHeaderIndices`.

**[[ScrollView.invertStickyHeaders]]**
If sticky headers should stick at the bottom instead of the top of the ScrollView. 

**[[ScrollView.contentOffset]]**
Used to manually set the starting scroll offset.

**[[ScrollView.horizontal]]**
When true, the scroll view's children are arranged horizontally in a row instead of vertically in a column.

**[[ScrollView.keyboardDismissMode]]**
Determines whether the keyboard gets dismissed in response to a drag.
