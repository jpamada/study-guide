#### Examples

**New Project**
```sh
npx create-expo-app@latest --template default@sdk-57
```

**Remove Template**
```sh
npm run reset-project
```

**Run Project**
```sh
npx expo start --clear
```

**Create a Production Export**
```sh
npx expo export --clear
```

**Update Compatible Packages**
```sh
npx expo install --fix
```
