#### Definition

**Hooks**
Let use different React features from components. Can use built-in or own.

___
#### Examples

**[[State Hooks]]**
Lets a component to remember information.

**[[Context Hooks]]**
Receive information from distant parents without passing it as props.

**[[Ref Hooks]]**
Let a component hold some information that isn't used for rendering.

**[[Effect Hooks]]**
Let a component connect to and synchronize with external systems.

**[[Performance Hooks]]**
Optimize rendering performance.
